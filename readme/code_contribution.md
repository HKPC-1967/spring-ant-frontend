## Future Release Plan 未来发布计划

For major changes or significant dependency upgrades, we will publish a GitHub Release.  
后续有大的改动，或依赖有大版本更新时，我们会发布GitHub Release。

Therefore, we recommend clicking watch -> custom -> releases on GitHub to receive release notifications as soon as possible.  
所以建议GitHub上面点watch -> custom -> releases，这样就能第一时间收到发布releases的通知。

We plan to upgrade once the new Ant Design Pro Release version is available (community contributions are welcome).  
我们计划Ant Design Pro有新的Release版本发布后，会基于最新的Release版本进行一次更新（也欢迎社区贡献）。

## Suggested Code Contribution Areas 建议贡献领域

You are welcome to contribute based one the current Ant Design Pro `master` branch: please keep two branches, the `original_ant_design_pro_code/master/commit_hash/607e63f4fdb49d78306a618f2b2c29291ce85500` and your updated branch. We are happy to review merge your pull request into a beta branch.  
欢迎基于当前Ant Design Pro的`master`分支进行贡献，您需要提交2个分支: 一个是`original_ant_design_pro_code/master/commit_hash/607e63f4fdb49d78306a618f2b2c29291ce85500`，另一个是您更新后的分支。我们很乐意review并merge您的pull request到beta分支。

## Code Contribution 贡献代码

We welcome all forms of contributions, including code, documentation, tests, and other improvements.  
我们欢迎任何形式的贡献，无论是代码、文档、测试还是其他方面的改进。

For example, updating deprecated methods, correcting typos, or improving documentation in Chinese or English are all welcome.  
比如更新下某个已经被标记为弃用的方法，错别字修正，中英文档完善等都是欢迎的。

For this Frontend project, we try to make only the core minimal code changes, so that people can compare the code clearly between `main` and `original_ant_design_pro_code/release_v6.0.0-beta.1` branches. And we expect Ant Design Pro to keep releasing new versions, so that we can keep our codebase up to date with minimal code changes.  
对于这个前端项目，我们尽量只做核心的最小化代码改动，这样大家就可以清晰地对比`main`和`original_ant_design_pro_code/release_v6.0.0-beta.1`分支之间的区别。 同时我们也期待Ant Design Pro持续发布新版本，这样我们就可以以最小的代码改动保持我们的代码库与最新版本同步。

Please ensure your pull request is well-tested and includes both Chinese and English comments (or English only).  
请确保您pull request的代码是仔细测试过的,以及有中英文或英文注释。

If you have specific ideas to discuss, feel free to email dtd-ai-code@hkpc.org, describing your ideas and planned contributions. We will create a WeChat or Discord group for contributors to facilitate communication and collaboration.  
如果您有具体想法想和我们沟通，也欢迎email dtd-ai-code@hkpc.org, 说明您的想法和计划贡献的内容，我们会创建个贡献者微信群或Discord群，方便交流与协作。
