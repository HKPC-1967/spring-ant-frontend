## 未來發佈計畫

後續有大的改動，或依賴有大版本更新時，我們會發佈 GitHub Release。

所以建議在 GitHub 上點選 watch -> custom -> releases，這樣就能第一時間收到發佈 releases 的通知。

我們計畫在 Ant Design Pro 有新的 Release 版本發佈後，會基於最新的 Release 版本進行一次更新（也歡迎社群貢獻）。

## 建議貢獻領域

歡迎基於目前 Ant Design Pro 的 `master` 分支進行貢獻，您需要提交 2 個分支：一個是 `original_ant_design_pro_code/master/commit_hash/607e63f4fdb49d78306a618f2b2c29291ce85500`，另一個是您更新後的分支。我們很樂意 review 並 merge 您的 pull request 到 beta 分支。

## 貢獻程式碼

我們歡迎任何形式的貢獻，無論是程式碼、文件、測試還是其他方面的改進。

比如更新某個已被標記為棄用的方法、修正錯字、完善中英文文件等，都是歡迎的。

對於這個前端專案，我們盡量只做核心的最小化程式碼改動，這樣大家就可以清楚地對比 `main` 和 `original_ant_design_pro_code/release_v6.0.0-beta.1` 分支之間的差異。同時我們也期待 Ant Design Pro 持續發佈新版本，這樣我們就可以以最小的程式碼改動，保持我們的程式庫與最新版本同步。

請確保您 pull request 的程式碼已仔細測試過，並且附有中英文或英文註解。

如果您有具體想法想和我們溝通，也歡迎 email dtd-ai-code@hkpc.org，說明您的想法和計畫貢獻的內容，我們會建立貢獻者微信群或 Discord 群，方便交流與協作。
