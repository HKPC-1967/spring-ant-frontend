## It's recommended to follow the Ant Design Pro's code convention.

## File naming conventions:

1. **React Component Files**: Use PascalCase (UpperCamelCase) for naming. This helps distinguish React components from regular JavaScript functions or variables.

- Example: `LoginForm.tsx`, `Admin.tsx`

2. **Regular JavaScript/TypeScript Files**: Use camelCase or kebab-case for naming.

- Example: `index.tsx`, `localStorageUtil.ts`
